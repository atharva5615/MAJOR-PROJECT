# CivicAI

AI-Powered Citizen Issue Reporting
and Resolution Platform.

## Overview

CivicAI uses artificial intelligence to detect
civic problems from uploaded images.

The platform supports:

- AI-based civic issue detection
- GPS location tracking
- Duplicate complaint detection
- Complaint priority scoring
- Municipal complaint management
- Geographic hotspot analytics

## Technology Stack

- React.js
- Tailwind CSS
- Python FastAPI
- PostgreSQL
- YOLO
- OpenCV
- Leaflet
